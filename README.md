# Validating Machine-Learned Driving Functions in Software-Defined Vehicles

M.Sc. thesis project (Reutlingen University, Professional Software Engineering) studying how organisations decide that a machine-learned driving function has enough evidence to release — and what happens to that decision after an over-the-air retraining.

## Research questions

1. How are AI-based features identified and selected for development in software-defined vehicles?
2. Which practices substitute for continuous experimentation where safety and process requirements prevent learning through release (shadow mode, re-simulation, proving ground, staged rollout)?
3. What can each substitute practice establish, and which questions remain unresolved at release — including after a field retraining?

## Method

Case study (Runeson & Höst): 5–20 semi-structured interviews across product, ML engineering, safety/quality and project roles, triangulated against internal process and validation documents.
